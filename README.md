# The Fires Lab

A browser-based workbook for the D3A targeting methodology — Decide, Detect,
Deliver, Assess — taught through one tactical scenario rather than a lecture.
Students build the four Decide products in order and are marked as they go.

Static HTML, CSS and JavaScript. No build step, no framework, no dependencies,
no network calls at runtime. Open `index.html` and it runs, from a web server
or straight off a USB stick.

## Languages

English and Traditional Chinese (繁體中文). The **EN / 繁中** switch sits at the
top right of every page and the choice is remembered.

## Status

Phase 1, Decide, is complete: four products across four pages, twelve tasks.
Phases 2, 3 and 4 are marked "Coming soon" while their content is written.

## Progress

Progress is stored in the visitor's own browser and is never sent anywhere.
Where the browser refuses to store anything, the course still runs and simply
does not remember between visits.
